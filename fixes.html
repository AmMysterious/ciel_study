Fixes & what's next

Last updated 04 August 2026 · 18 entries

If you report a problem, you should be able to see what happened to it. This page lists every issue I've fixed in the question bank, the bot and the payment flow — including the ones that were my fault.

Found something wrong, or want to suggest something? Send /feedback in the bot — that is the only place I track requests. You get a ticket number, you can check its status with /myfeedback, and you'll be messaged when it's actually fixed rather than left wondering. Suggestions go in the same place; if I build yours, it shows up below.

Milestones

The bigger upgrades I'm working towards, and what each one has to wait for. No dates — each is gated on something real rather than a day I'd rather not miss.

GoalHappens when
🔨Always-on hosting, 24/7
Right now the bot runs on my own laptop, so it can only answer while that machine is awake. Nothing is ever lost — messages queue and payments are picked up automatically — but you can be left waiting. Moving to a proper server ends that.		Subscriptions cover the monthly server cost
⏭Instant payment confirmation, every time
Access already unlocks by itself, usually in seconds. Once the bot is on a server with a fixed address, the confirmation is immediate and never depends on my laptop being on.		The move to always-on hosting is done
⏭Every image question available
89 image-based questions are held back because I can't yet read the figure clearly enough to be certain of the answer. I would rather withhold a question than serve one I'm unsure of.		Each figure has been re-checked by hand

Both are already in the bank and both keep growing. FMGE is the deepest today; the aim is for all three to feel equally complete.		Ongoing — questions are added every week
